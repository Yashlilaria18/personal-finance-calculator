# Personal Finance & Salary Calculator

My first Python project built while learning Python programming.

## About the Project
This program calculates an employee's salary, monthly expenses,
and savings based on user input.

## Features
- Employee personal information
- Basic salary input
- HRA calculation (20%)
- DA calculation (10%)
- PF deduction (12%)
- Gross salary calculation
- Net salary calculation
- Monthly expense calculation
- Monthly savings calculation
- Annual savings calculation

## Python Concepts Used
- Variables
- Data Types
- User Input
- Type Conversion
- Boolean Values
- Arithmetic Operators
- F-Strings

## How to Run

1. Install Python.
2. Download this repository.
3. Open the project folder in VS Code.
4. Run the following command:

python project_1.py

## Learning Objective
Practicing Python fundamentals through a real-world
salary and personal finance calculator.
